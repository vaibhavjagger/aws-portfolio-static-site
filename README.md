A **responsive static portfolio website** built with HTML, CSS, and JavaScript — hosted on **AWS S3** using the Free Tier.

---

## ✨ Features

- **Fully responsive**: Optimized for both mobile and desktop interfaces
- **Hosted on AWS S3** as a static website
- **Zero-cost architecture** leveraging AWS Free Tier
- Minimal and performance-friendly front-end design
